# StatTile

One headline figure with a plain-language label and one line of context; clickable when it leads somewhere.

## Classes

`.k-stat` (an `<a>` when it links) holding `.k-stat-label`, `.k-stat-value`, `.k-stat-meta` (`--danger` when the context is bad news).

## Rules

- Label as a sentence about the user's money: "Customers owe you", "You owe suppliers".
- The meta line says what is behind the number or what to do: "All of it overdue · 5 invoices".
- Four tiles at most, in a grid that wraps at 220px.

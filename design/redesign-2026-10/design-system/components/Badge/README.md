# Badge

A count of work waiting behind a nav item or tab; it disappears at zero.

## Classes

- `.k-badge--brand`: work you can do now (lines to match).
- `.k-badge--danger`: something is late (overdue invoices).
- `.k-badge--neutral`: work waiting on someone else or not urgent (bills to approve).

## Rules

Give the parent an accessible name that includes the count ("Bank, 15 lines to match"). Never show a badge with 0.

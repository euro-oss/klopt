# Callout

An inline message about the thing on screen, with the single action that resolves it.

## Classes

`.k-callout` with `--warn` (brand-tint) or `--danger`; inside an icon, `.k-callout-body` (`.k-callout-title`, `.k-callout-text`) and one link or button.

## Rules

- Title says the consequence, text says why, the link fixes it.
- Never stack two callouts. Never use one for a success: show the result instead.
- No permanent banners: the old "Demo environment" bar belongs in the administration switcher as a label.

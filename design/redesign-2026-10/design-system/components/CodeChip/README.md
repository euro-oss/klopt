# CodeChip

A machine code shown next to its plain name: VAT codes, RGS codes, ledger numbers, VAT return boxes, hashes.

## Classes

`.k-code`: JetBrains Mono 11px on `surface-sunken`.

## Rules

- Always next to a plain-language name, never instead of it ("Sales at 21% `1a`").
- Ledger numbers and RGS codes show only with *Show accounting detail* on; VAT return boxes and hashes always show.

# DropZone

The place files land: receipts in the Inbox, bank statements, audit files to import.

## Classes

`.k-drop`, with `.is-over` while a file is dragged over it. Inside: a bold line saying what to drop, a line naming the accepted formats, and a button to choose a file.

## Rules

- Name the formats in the user's words and the technical ones ("CAMT.053 or MT940, any bank").
- The whole page accepts drops where a zone is shown; the zone only explains it.
- Paste (`⌘V`) works wherever a drop zone does.

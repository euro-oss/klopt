## A11y deviations (documented)

1. **Yellow text links.** Export yellow (`#ffd43b`) as text is ~1.43:1 on white.
   Phase 0 uses `--link` = `--brand-ink` with underline.
   - Light: `#8a6a00` on `#ffffff` ≈ **5.07:1** (AA)
   - Dark: `#f5c518` on `#111113` ≈ **11.57:1** (AA)

2. **Input / control borders.** Export `--line-control` `#c9c8c1` is ~1.68:1 on
   white. Phase 0 uses `--input-border` `#8a8980`:
   - Light on `#ffffff` ≈ **3.52:1**; on `--ground` `#f5f5f2` ≈ **3.22:1**
   - Dark on `#111113` ≈ **5.36:1**
     Interactive controls keep a **44px** minimum hit area below `md`
     (`--control-h-touch`).
